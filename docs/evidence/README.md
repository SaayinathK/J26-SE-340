# Historical evidence

The former root `evidence/` folder is now `docs/evidence/`, preserving Planner workbooks, model evaluation exports, reports and logs. Existing report contents and embedded source paths represent the audited historical snapshot; relocation does not rerun or recalculate that evidence.

Use current source paths from the [project overview](../../README.md) and [architecture](../architecture/README.md). New verification logs and disposable browser screenshots are written under ignored `.local/` directories. Planner generator modules remain here for provenance; regenerating the historical workbook against changed source anchors requires a fresh audit.
