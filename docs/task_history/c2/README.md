## Import policy

The supplied working tree did not include Git history. Its existing files are being
imported into the assigned branch while preserving the original remote skeleton commit.
Author and committer timestamps are backdated according to the workbook at the user's request.
This is a retrospective import, not proof of historical authorship, work dates or completion.
Original embedded artifact timestamps have not been rewritten. Some intermediate commits
are partial source snapshots and are not independently runnable.

Date selection: explicit actual-completion note, otherwise Completed Date, otherwise
Due date, otherwise Start date. For two undated optional tasks, only the record's Git
date uses the workbook export date; their task dates stay unspecified. The time of day
is not in the spreadsheet: noon plus ten-minute ordering intervals was chosen in +05:30.
Some new dates precede the preserved parent commit's date because the source workbook
includes earlier tasks; the existing remote history has not been changed to hide this.
