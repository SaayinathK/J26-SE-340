# Homepage imagery

Created for the Ciftron public homepage with the built-in image_gen tool. These are illustrative marketing assets, not photographs of the actual Ciftron team or product screenshots. Originals are preserved in the generation output directory; project assets are JPEG copies encoded at quality 90 for fast loading.

```text
Constraints: no text, no letters, no numbers, no logos, no people, no interface screenshot, no clutter, no watermark. Deliver a finished bitmap image.
```
